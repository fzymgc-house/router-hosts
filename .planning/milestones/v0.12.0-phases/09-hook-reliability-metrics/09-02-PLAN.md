# Phase 9 Plan 02 — Hook Timeout Configuration Chain and Validation

<objective>
Complete the timeout resolution chain promoted in Plan 09-01: add the server-level
`[hooks] default_timeout` middle link, make the resolution a single named operation, and
prove the resulting invariant — after a successful config load every hook carries a
positive effective timeout, whichever combination of keys the operator wrote.

Purpose: HOOK-02's configurability half. Plan 09-01 established per-hook `timeout` →
built-in 30s; this plan inserts the server-level default between them and closes the
validation, encoding, and empty-input edges.

Output: a config surface that cannot produce a non-positive effective timeout, with an
explicit table of decode edges including the bare-integer nanoseconds footgun.
</objective>

**internal/config/server.go**

- Add `DefaultTimeout time.Duration` with TOML tag `default_timeout` to `HooksConfig`.
- Add `func (h *HooksConfig) resolveTimeouts() error`. It performs, in order:
  1. when `h.DefaultTimeout` is the zero value, assign `DefaultHookTimeout`;
  2. for each element of `h.OnSuccess` and `h.OnFailure`, indexed by position so the
     assignment mutates the stored element rather than a loop copy, when its `Timeout` is
     the zero value assign `h.DefaultTimeout`;
  3. after resolution, if `h.DefaultTimeout` is not strictly positive, or any hook's
     resolved `Timeout` is not strictly positive, return
     `oops.Code(domain.CodeValidation).Errorf(...)` naming the offending key or hook name
     and the offending duration. This step is the enforcement point for the promoted
     invariant and is what makes "must be > 0" true at config-validation time without
     making `HookDefinition.validate()` reject a bare zero.
- Replace the ad-hoc per-hook defaulting loop that Plan 09-01 added to `LoadServerConfig`
  with a single `if err := cfg.Hooks.resolveTimeouts(); err != nil { return nil, err }`,
  placed after the `meta.Undecoded()` strict-key check and before `cfg.validate()`. Keep
  it adjacent to the existing retention/ACME/OTel defaulting blocks so the file reads as
  one defaulting region.
- Do NOT move, wrap, or bypass `checkConfigPermissions(path)` — it must remain the first
  statement of `LoadServerConfig`, because the file it guards now carries timeout keys in
  addition to hook commands.
