## Follow-Up Identified — OUT OF MILESTONE SCOPE

**`docs/guides/operations.md:127` misdescribes SIGHUP behavior.** It states:

> 3. If valid: graceful shutdown (30s drain), restart with new certs

The code does neither. `server.go:133-138` performs an **in-place** `reloadCert()`;
only SIGTERM/SIGINT reach `gracefulStop()`. An operator reading this would expect
in-flight RPCs to be drained on a cert reload, and would plan reload windows around
a restart that never happens.

This is a **pre-existing Phase-2-era documentation defect**, surfaced incidentally
while auditing Phase 9's shutdown interaction. It is **not** a Phase 9 regression
and does not block this milestone. Filed as [#392](https://github.com/fzymgc-house/router-hosts/issues/392).
