# Phase 7 Plan 02 — All Three Route Kinds and Hostname Filtering

<objective>
Expand the proven HTTPRoute slice to all three route kinds and put every hostname
through one filter before it can become a DNS entry.

Purpose: GW-01 names three kinds, and an unfiltered hostname is the phase's most
direct route to a bad DNS record (a literal `*.example.com` entry, or a name the
router's own validator would reject).
Output: `gatewayRouteKinds()` complete; `hostnamesOf`/`parentRefsOf` covering all
three kinds; `extractHostnames` enforcing D-18 and D-19.
</objective>

Complete `extractHostnames(log *slog.Logger, obj client.Object) []string` in
`internal/operator/gateway_controller.go` so every hostname passes, in order:

   entry) — `strings.HasPrefix(h, "*")`.

   preserving first-appearance order.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kubernetes API server → operator | `spec.hostnames` is fully attacker-controlled text from any principal with route-create rights |
| operator → router-hosts gRPC server | An accepted hostname becomes an authoritative DNS record on the router |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-07 | Tampering | `extractHostnames` (ASVS V5 Input Validation) | high | mitigate | Every hostname passes `internal/validation.ValidateHostname` before any `HostClient` call, and `*`-prefixed wildcards are rejected outright rather than passed through as a literal record. Failures are skipped and logged, never fatal, so one bad name cannot deny service to the rest of the route. |
| T-07-10 | Denial of Service | `extractHostnames` de-duplication | low | mitigate | A route repeating one hostname N times yields one entry, so a single object cannot fan out into N server writes per reconcile. |
| T-07-11 | Tampering | dot-less hostname acceptance (D-19) | low | accept | Under ADR `router-hosts-bzg` a bare name renders as `local-zone: "<name>." static`, making unbound authoritative for a whole pseudo-TLD. PROJECT.md records this as a known, project-wide, deliberately unenforced footgun; enforcing it here alone would make the operator inconsistent with HostMapping and IngressRoute. A warning is emitted. Cross-cutting enforcement is a CONTEXT Deferred Idea. |

</threat_model>
